## Cowboy MCP (GPL-2.0-or-later)

Parts of Llamly were modelled on [Cowboy MCP](https://wordpress.org/plugins/cowboy-mcp/) 1.7.1 by februality, licensed GPL-2.0-or-later. Llamly redistributes under the same license family (GPL-2.0-or-later). No Cowboy MCP file is shipped, loaded or required, and no source file was copied as a whole; the Llamly code was written in its own namespace (`Llamly\Free`), REST namespace (`llamly/v1`), option, table and hook prefixes (`llamly_free_`). Cowboy MCP is credited here because its design was studied closely and reused selectively:

* **Connection forms and recipes** (`assets/free/js/admin.js`): the same ways to connect (remote OAuth for claude.ai, Claude Desktop, ChatGPT and Cursor; Bearer key for Claude Code, Codex, Cursor, Gemini CLI and OpenCode; the `mcp-remote` bridge for Claude Desktop with a local site), the client commands/config snippets and the claude.ai "add custom connector" link. Changed: an Antigravity CLI recipe was added in place of the Gemini CLI one (and the Gemini logo removed); keys belong to the WordPress user who created them instead of the first administrator, per-key scopes (full, read only, chosen categories), live "first request received" status, Portuguese copy.
* **OAuth 2.1 server** (`src/Free/Auth/OAuthServer.php`, `OAuthRedirectPolicy.php`, `WellKnown.php`): discovery documents, dynamic client registration with a time-limited registration window, PKCE, redirect-host allowlist (including the local-site heuristic and Cursor's mixed redirect lists). Changed: hashed codes and tokens in dedicated tables, per-IP registration rate limit and client cap, consent screen with scope choice, refresh rotation and revocation, registration window that never disconnects existing clients.
* **Streamable HTTP transport and gateways** (`src/Free/Mcp/*`): POST JSON/SSE negotiation, 202 for notifications, 405 for GET, 204 for DELETE with session ownership, and the two gateway tools `llamly_discover` / `llamly_run` modelled on `cowboy_discover` / `cowboy_run`. Changed: one dispatcher shared by MCP, gateways, Abilities and admin (schema, capability, scope, safe mode/permit, snapshot, revision check, journal, audit), no recursion through the gateway.
* **Tool catalogue** (`src/Free/Tools/*`): tool names and argument shapes follow Cowboy's core WordPress tools for correspondence. Changed: every write is journaled with undo/redo and conflict detection; file, SQL, shell, WP-CLI, HTTP, plugin/theme management and Elementor writes are not included.
* **Diagnostics, undo journal and database checkpoints** (`src/Free/Admin/Doctor.php`, `src/Free/History/*`, `src/Free/Checkpoint/*`): the concepts of a connection doctor, a per-change undo journal and database restore points. Changed: Llamly implements its own journal with per-object versions and redo, and its restore points live in Llamly tables (no `.sql.gz` files in uploads), use keyset pagination, a durable restore journal and preserve users, sessions, roles, Application Passwords and Llamly connections.
